# EEC Table Inventory

Generated by `eec-tables-build` by parsing each chapter's `## Proposed Tables` section
(a sibling to "Proposed Maps and Figures," which `FIGURE_INVENTORY.md` tracks separately —
this file exists because that one explicitly excludes "Proposed Tables"). Mirrors
`FIGURE_INVENTORY.md`'s structure and status vocabulary where applicable.

## Status vocabulary

- `todo` — proposed table identified, not yet rendered
- `in-review` — rendered (Pattern 1 or Pattern 2 per `docs/authoring/table-standards.md`), awaiting Greg's placement sign-off
- `needs-data` — candidate identified, no cited source found for the numbers it would need
- `already-covered` — the chapter's body prose already contains a built table (Table N-A/B/C style) that substantively satisfies this proposed item; flagged for Greg to confirm the backlog row can close without a new render
- `done` — reserved; never self-assigned by this task. Only set after Greg confirms placement.

## Chapters with no `## Proposed Tables` section

Some chapters (e.g., Ch01, Ch05) have no separate "Proposed Tables" backlog list because
their body prose already ships fully-built tables (Table 1-A/1-B, Table 5-A/B/C). These
chapters are considered N/A for this tracker, not `todo` — they carry no row below unless
a future draft revision adds a genuine backlog list. Not counted toward the `tables:`
frontmatter flag scope.
