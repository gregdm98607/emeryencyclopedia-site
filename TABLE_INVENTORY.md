## Status vocabulary

- `todo` — proposed table identified, not yet rendered
- `in-review` — rendered (Pattern 1 or Pattern 2 per `docs/authoring/table-standards.md`), awaiting Greg's placement sign-off
- `needs-data` — candidate identified, no cited source found for the numbers it would need
- `already-covered` — the chapter's body prose already contains a built table (Table N-A/B/C style) that substantively satisfies this proposed item; flagged for Greg to confirm the backlog row can close without a new render
- `done` — reserved; never self-assigned by this task. Only set after Greg confirms placement.
