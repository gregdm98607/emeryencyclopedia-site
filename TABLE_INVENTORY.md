# EEC Table Inventory

Generated by `eec-tables-build`, parsing each chapter's `## Proposed Tables` section — the sibling to "Proposed Maps and Figures" that `FIGURE_INVENTORY.md` explicitly excludes. Mirrors `FIGURE_INVENTORY.md`'s structure: chapter, planning ID, subject, status, notes.

## Status vocabulary

- `todo` — inventoried, not yet rendered
- `in-review` — rendered (Pattern 1 or 2 per `docs/authoring/table-standards.md`), awaiting Greg's placement sign-off
- `needs-data` — candidate identified, no cited source found yet
- `fulfilled-in-chapter` — the chapter already ships a fully-built, in-body table matching this proposal 1:1 (predates this job); no action needed
- `done` — reserved; never self-assigned by this job, only after Greg confirms placement

## Planning IDs

Carried over verbatim where the chapter uses its own tag (`T1`–`T4`, Ch02). Auto-numbered per chapter in reading order where the chapter uses plain numbered prose, with an `(auto)` suffix — the number is this inventory's own ordering, not a number appearing in the chapter text.
