# Timeline renderer

A reusable matplotlib-based timeline generator for the Encyclopedia of Emery
County. Replaces the ad-hoc, one-off matplotlib scripts that produced the
overlap-broken charts in `public/images/chapters/Rejected/`.

## Why this exists

The original ch26–29 timelines were generated by throwaway Python scripts
written inside past Cowork sessions. They had no label-collision avoidance,
so any chapter with clustered events (e.g. ch27's 1877–1909 cluster, ch29's
2006–2023 cluster) produced overlapping text. There was also no committed
artifact, so every regeneration meant a fresh prompt and a fresh script with
no guarantee of visual consistency.

This tool fixes both problems:
- Event data lives in version-controlled YAML.
- One renderer (`make_timeline.py`) handles every chapter, so the visual
  language stays consistent across the book.
- `adjustText` + greedy lane assignment + a 32-char label cap prevent
  overlap on dense datasets.

## Install

```bash
pip install adjustText pyyaml matplotlib
```

## Usage

```bash
python tools/timelines/make_timeline.py ch29
```

This reads `tools/timelines/data/ch29.yaml` and writes
`public/images/chapters/<out_basename>.png`.

## Data schema (YAML)

```yaml
title: "Chapter title for the chart"
subtitle: "Optional subtitle"
out: "ch29_opensource_health_safety_timeline.png"
source: "Free-text source line for the bottom credit."

categories:
  - {key: pioneer, label: "Pioneer / memorial", color: "#A0522D"}
  - {key: state,   label: "Public health",      color: "#2C5F7C"}

events:
  - {year: 1877, category: pioneer, label: "Castle Valley midwifery era"}
  - {year: 1918, category: state,   label: "Influenza pandemic"}
  # Optional `side: above` or `side: below` overrides auto-placement.
  # Labels longer than 32 chars are auto-truncated with a footnote marker.
```

## Design notes

- **Canvas:** 12x6 in @ 200 DPI = 2400x1200 px. Wider than the rejected
  PNGs, which were squeezed into bar-chart proportions.
- **Lane assignment:** greedy. Walks events left-to-right and alternates
  above/below by default. If a label would collide with another label
  on the same side+lane within an 8-year window, it gets bumped to the
  next lane (further from the axis).
- **Label cap:** 32 chars. Anything longer is truncated to "...[N]" and
  the full text is rendered as a footnote at the bottom.
- **Palette:** Desert Scholarly (sandstone, canyon-shadow, sage-green,
  mesa-red, sky-wash, deep-sky) — hard-coded in `make_timeline.py` to
  match `src/styles/global.css`.
- **adjustText pass:** runs after lane assignment, in y-axis only, to
  resolve any residual local collisions without breaking the
  category/lane structure.

## When to add a new chapter

1. Add `tools/timelines/data/chXX.yaml` with the schema above.
2. Run `python tools/timelines/make_timeline.py chXX`.
3. Spot-check the output. If overlap remains, the dataset is too dense:
   either drop the lowest-importance events, shorten labels further, or
   split into two timelines (e.g. pre-1950 and post-1950).
4. Commit both the YAML and the PNG.
